# Falling Pickaxe — Vercel static project

Готовый статический сайт. Не требует Node.js, сборки, пакетов, переменных окружения или дополнительных файлов с картинками.

## Как загрузить

1. Распакуй ZIP. Файлы `index.html` и `vercel.json` должны находиться непосредственно в корне проекта, не внутри дополнительной вложенной папки.
2. В Vercel создай проект из этой папки (например, через GitHub, CLI или Vercel Drop) либо загрузи папку целиком в Vercel Drop.
3. В настройках проекта выбери **Framework Preset: Other**. **Root Directory: `.`**. **Output Directory: `.`** (или используй настройки `vercel.json`). **Build Command: none / blank**.
4. Выполни новый Deploy. Открой адрес проекта без добавления имени файла: `/`.

**Важно:** Если проект уже существует и продолжает показывать 404, проверь Settings → Build and Deployment: отсутствуют ли старые переопределения Root Directory или Output Directory; проверь, что в Deployments → Source присутствует `index.html`.
